ALEXA / Guardian X - build notes

Included:
- Complete project source, handlers, keyboards, middleware, models, migrations, locales, and tests.
- Content locks for text, links, photos, videos, GIFs, audio, voice, documents, polls, games, bots, forwards, contacts, locations, stickers, inline buttons, mentions, and hashtags.
- /lock all and /unlock all update every supported lock field.
- Lock settings are committed before the bot reports success; database save failures return an error.
- Existing owner panel, group management, moderation, games, and database fallback code are retained. AI commands and integrations have been removed. English-only messages and group admin-permission prompts are enabled.

Group lock commands:
  /locks
  /lock all
  /unlock all
  /lock links
  /unlock links
  /lock photos
  /unlock photos

Deployment:
1. Extract this ZIP into a clean folder.
2. Copy .env.example to .env and fill BOT_TOKEN and OWNER_ID (or BOT_OWNER_ID).
3. Install dependencies with: python3 -m pip install --user -r requirements.txt
4. Start with: python3 -m bot.main

Final promotion and auto-delete update (2026-10-16):
